Money & Beat Tracker Web App

How to use on Windows:
1. Extract the ZIP.
2. Double-click index.html to open it in a browser.
3. Enter Beat Amounts and edit Money Paid if needed.
4. Data is saved locally in the browser.

Best way to use on iPhone:
1. Host these files on any simple web host (GitHub Pages, Netlify, Vercel, etc.).
2. Open the hosted link in Safari.
3. Tap Share > Add to Home Screen.

Logic:
- 30 serial numbers.
- Dates run on the 10th of each month starting 10 Feb 2026.
- Money Paid defaults to ₹30,000 and remains editable.
- Net Amount = Base Amount - Beat Amount.
- Cumulative Beat adds Beat Amount row by row.
- If a row reaches/exceeds Base Amount, the NEXT row restarts cumulative beat from that row's Beat Amount.
